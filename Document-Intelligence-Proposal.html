🏗️ Overview

Overview

What it does in one sentence: A salesperson submits a client brief, AI automatically drafts a technical + commercial proposal, four internal teams review and approve it in parallel, and the system exports a branded Statement of Work document — all in minutes instead of days.

Problem Solved

Manually writing SOWs takes days, requires multiple meetings, and is error-prone. This platform automates the entire lifecycle.

Primary Users

Sales, Technical Architects, Finance analysts, and Management decision-makers at a professional-services firm.

Core Output

A signed-off, downloadable Word/PDF Statement of Work with effort estimates, team allocation, and pricing.

Key Innovation

GPT-4o reads past successful projects and current rate cards to produce a first-cut proposal with zero human effort.

Business Value

Without this platform, proposal creation requires a project manager to collect inputs, a solutions architect to design the approach, a finance analyst to build the budget, and management sign-off — each in sequence. Each hand-off adds 1–3 days. Document Intelligence Proposal collapses that to hours by running AI generation and team reviews in parallel.

Speed

First AI draft ready in < 30 seconds. Full multi-team review trackable in real time.

Consistency

Every proposal uses the same template, the same rate card, and the same approval checklist — no ad-hoc formatting.

Traceability

Full audit log of who approved what and when. Every revision is versioned.

Knowledge Reuse

Historical project library feeds AI context so each new proposal learns from past wins.

▶️ Process

How It Works — Step by Step

Below is the full journey from a sales enquiry to a signed-off SOW document, written for a non-technical audience.

1
Sales logs in and submits a lead

A salesperson fills in a short form: client name, project description, budget range, timeline, and technology preferences. This takes two minutes.

2
AI reads the brief and finds similar past projects

The system searches the internal library of completed projects to find the best matches by industry and technology stack.

3
GPT-4o drafts the full proposal

OpenAI's model reads the brief, the similar projects, and the current rate card, then generates a structured proposal covering: executive summary, technical architecture, team composition, effort estimates, and commercial pricing. This takes under 30 seconds.

4
Four teams are notified simultaneously

Sales, Tech, Finance, and Management each receive a Zoho Cliq message and an in-app notification to review their section. Reviews happen in parallel — no waiting for the previous team to finish.

5
Each team edits and approves their section

Teams can edit their part of the proposal using a rich text editor. Once satisfied, they click Approve. If they need changes from another team they can request a revision with a comment.

6
Teams discuss in real-time chat

Each proposal has a built-in group chat where all teams can ask questions or flag issues without leaving the tool — no need for separate email chains.

7
Management gives final approval

Once all four teams approve, management can give the final sign-off, which locks the proposal.

8
A branded Word / PDF document is generated

The system fills in the company's SOW template with all approved content and makes it available for download. The document can also be sent via Zoho Writer for digital signature.

9
Approval reminders run automatically

A background job checks every 2 hours for pending approvals that are overdue and sends reminders via Zoho Cliq and email — no one needs to manually chase reviewers.

AI Scoping Pipeline

The AI proposal generation runs as an asynchronous background pipeline so the UI is never blocked:

Lead Created → Job Queued (DB) → Worker Polls (2 sec) → Similar Projects Lookup → Rate Card Estimation → GPT-4o Prompt → Scoping Result Cached → Proposal Sections Created

Approval Workflow Pattern

Parallel, not sequential. All four teams receive their review tasks simultaneously. The proposal is considered ready for final management sign-off only when every team has set their approval status to "Approved". A single rejection or revision request by any team blocks the final sign-off until resolved.

Real-time Communication

SignalR — Notifications Hub

Pushes live proposal status updates and approval events to logged-in users. No page refresh needed.

SignalR — Chat Hub

Each proposal has a group chat room. All team members connected to a proposal receive messages instantly.

Zoho Cliq

External webhook-based notifications sent to team Cliq channels when a proposal is ready for review or has been approved.

Key Design Decisions

No Stored Procedures

All data access is through EF Core. Migrations are code-first and version-controlled. Enables easy refactoring.

Async Background Jobs

AI scoping runs in a background hosted service, preventing API timeouts and allowing the UI to poll for status.

JWT Multi-Team Claims

A single JWT can carry memberships for multiple teams, so one user can review across departments.

Optimistic Concurrency

Proposal section edits use EF Core's concurrency tokens to prevent two users overwriting each other.

🔗 Integrations

External Integrations

OpenAI (GPT-4o)

The core AI engine. Sends a structured prompt containing the client brief, similar historical projects, and rate card data. Receives a JSON response with executive summary, technical architecture, effort breakdown, team composition, and pricing. Model, temperature, and API key are user-adjustable at runtime.

Zoho Cliq

Sends instant notifications to four team channels when a proposal is ready for review. Uses incoming webhook URLs per channel. Messages include a direct deep link to the proposal review page. Credentials stored in Azure Key Vault.

Zoho Writer

Used for advanced PDF/Word document generation from a Zoho template. A webhook callback (/api/zoho/webhook/doc-ready) signals when the document is ready for download. HMAC signature verified for security.

Azure Key Vault

Stores sensitive configuration at runtime: OpenAI API key, Zoho credentials, SMTP password, JWT secret. Application identity uses Azure Managed Identity for passwordless vault access.

SMTP Email

Sends email notifications when a proposal requires approval or when an approval reminder fires. SOW documents are optionally attached.

Azure Application Insights

Planned telemetry integration for monitoring API performance, tracking errors, and measuring proposal generation latency in production.
