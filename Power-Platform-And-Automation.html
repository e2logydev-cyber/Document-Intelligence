🎯 Project Overview

Overview

What it does in one sentence: A Power Pages public website lets attendees browse and register for events, Power Automate handles automated confirmations and reminders, Power BI delivers real-time analytics, Copilot Studio answers attendee questions via AI chat, and all data is stored centrally in Dataverse.

Power Pages

Public-Facing Website

Event listing, registration forms, feedback, and contact pages — all built with Power Pages. Custom coding supported via Visual Studio Code.

Power Automate

Automated Workflows

Three automated workflows: registration confirmation email, pre-event reminder, and post-event feedback request — all triggered without manual intervention.

Power BI

Real-time Analytics

Embedded dashboard providing live insights into registrations, ticket sales, and attendee trends. Directly integrated into the Power Pages website.

Copilot Studio

AI Chatbot

Conversational AI assistant configured with event-specific topics to answer attendee questions — from event listings to registration support.

Dataverse

Central Data Store

All event and registration data is stored in a structured, secure, and scalable Dataverse database with multiple tables and configurable views.

Business Value

Traditional event management requires separate tools for registration, communications, analytics, and support — leading to data silos, manual effort, and a fragmented attendee experience. This system unifies the entire event lifecycle on a single platform using Microsoft Power Platform's no-code/low-code capabilities, reducing operational overhead and delivering real-time visibility.

Seamless Experience

Attendees register, get confirmations, receive reminders, and get support — all through one integrated platform without switching tools.

No-Code Automation

Power Automate workflows eliminate manual email sending for confirmations, reminders, and feedback requests.

Instant Insights

Admins see real-time registration counts, ticket sales, and attendee trends without waiting for manual reports.

Always-On Support

The AI chatbot handles attendee queries 24/7 with consistent, topic-driven responses — no support staff required.

⚙️ Workflow

How It Works — Step by Step

The complete journey from attendee discovery to post-event feedback, fully automated by the Power Platform.

1
Attendee visits the Power Pages website

The public website — built on Power Pages — presents the Home page, an About Us section, and a full Event Listing. Attendees can browse all upcoming events and view detailed information for each one.

2
Attendee registers for an event

From the Event Listing page, an attendee selects an event and completes the registration form. On submission, the registration record is saved directly to Dataverse.

3
Power Automate sends a confirmation email

The registration trigger in Dataverse activates a Power Automate workflow that immediately dispatches a personalised confirmation email to the attendee, confirming their spot at the event.

4
Reminder email sent before the event

Another Power Automate workflow fires on a scheduled basis before the event date, sending a reminder to all registered attendees with event details and any last-minute information.

5
Attendee can ask questions via the AI chatbot

At any point, attendees can use the Copilot Studio chatbot on the website to ask questions. The chatbot responds based on configured topics — for example, asking for the event list returns all available events from Dataverse.

6
Feedback request sent after the event

Once the event concludes, Power Automate automatically sends a feedback request email to attendees. Responses are collected through the Feedback page and stored in Dataverse for review.

7
Admin manages events and monitors analytics

Administrators use the admin panel within Power Pages to create, edit, or delete events. They can also download the full event list as an Excel file. The embedded Power BI dashboard provides a real-time view of registrations, ticket sales, and attendee trends.

Automation Flow

Attendee Registers → Dataverse Record → Confirmation Email → Event Reminder → Event Occurs → Feedback Request

👤 User Management

How to Add a New User

Three steps to invite and register a new user on the Power Pages portal via Portal Management.

Step 1 — Create a Contact Record

In Portal Management, go to Portals → Contacts, click + New, and fill in the required fields below.

FieldValueRequired
First NameUser's first nameYes
Last NameUser's last nameYes
EmailValid email addressYes
UsernameLogin name for local sign-inYes *
Web RolesClick lookup → select role(s)Recommended

* Username is required for local authentication. For external providers (Microsoft, Google, etc.), the email address is used as the username.

Assign Web Roles: In the Contact form, scroll to Web Roles → click + Add Existing Web Role → select the appropriate role → Save & Close.

RolePurpose
Authenticated UsersBasic logged-in access
AdministratorsFull admin access
Custom RolesYour defined permissions

Step 2 — Create an Invitation Record

In Portal Management, go to Portals → Invitations, click + New, and fill in the form.

FieldValueNotes
NameDescriptive namee.g., "Invite: John Doe"
ContactLookup → select Contact from Step 1Links invitation to the user
Invitation CodeLeave blank for auto-generation, or enter a custom unique codeMust be unique across all invitations
Expiry DateFuture date/timeDefault: 7 days from creation
WebsiteLookup → select your portalRequired for URL generation
Redirect URLOptional portal page pathWhere user lands after registration

After saving, the Invitation Code field displays the generated value — copy it for use in the registration URL in the next step.

Step 3 — Send Invitation to User

Build the registration URL using the Invitation Code from Step 2, then email it to the user.

Registration URL Format

https://[your-portal-domain]/SignIn/Register?invitation=[INVITATION_CODE]

Example:

https://site-ktahb.powerappsportals.com/SignIn/Register?invitation=a1b2c3d4-e5f6-7890-abcd-ef1234567890

Email to User

What to Include

Welcome message · Registration URL · Expiry date · Instructions to click the link and set a password.

User Action

What the User Does

User clicks the link, is taken to the registration page, sets a password, and is automatically logged in with the assigned web roles.
